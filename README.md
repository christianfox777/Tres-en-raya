# Tres en Raya v1.0
**Fecha de inicio:** 27/09/2026
**Integrantes:** Christian Suarez, Nicolas Rivera y Christopher Barreno.
## Descripción del proyecto
Este repositorio corresponde al desarrollo de nuestro videojuego **Tres en Raya v1.0**, realizado como proyecto integrador del primer trimestre de la Universidad Internacional del Ecuador.

El proyecto consiste en desarrollar el clásico juego de Tres en Raya utilizando Python, con una interfaz gráfica que permita a dos jugadores participar en una misma partida. Durante su desarrollo hemos trabajado en la programación de la lógica del juego, la creación del tablero y la implementación de diferentes funciones para mejorar su funcionamiento, también ell trabajo se realiza de manera colaborativa, por lo que utilizamos GitHub para compartir los avances y mantener un registro de los cambios realizados por cada integrante.

## Tecnologías utilizadas

Para desarrollar el proyecto hemos utilizado las siguientes herramientas:

- **Python:** es el lenguaje de programación que utilizamos para desarrollar la lógica y el funcionamiento del videojuego.
- **Tkinter:** es la biblioteca que utilizamos para crear la interfaz gráfica, incluyendo la ventana principal, los botones y el tablero de juego.
- **Random:** módulo de Python que utilizamos para realizar la asignación aleatoria de los símbolos X y O entre los jugadores.
- **Git:** herramienta que nos permite llevar un control de las versiones y modificaciones del código.
- **GitHub:** plataforma donde almacenamos el proyecto y compartimos los avances con los demás integrantes.
- **Claude:** herramienta de inteligencia artificial que utilizamos como apoyo para resolver algunas dificultades durante la programación.

## Funcionalidades

Entre las funcionalidades desarrolladas hasta el momento se encuentran:

- Ventana de inicio del videojuego.
- Tablero de Tres en Raya de 3 × 3.
- Participación de dos jugadores.
- Asignación aleatoria de los símbolos X y O.
- Alternancia de turnos entre los jugadores.
- Validación de las filas, columnas y diagonales para identificar al ganador.
El proyecto continúa en desarrollo, por lo que algunas funcionalidades todavía se encuentran pendientes de implementación.
